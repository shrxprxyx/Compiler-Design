PROCEDURE:
1. Open a text editor and write the FLEX source file art_expr.l. Define regular expressions for identifiers, digits, operators, and ignore whitespaces.
2. Save and close the FLEX file.
3. Open another text file and write the BISON source file art_expr.y. Define tokens and grammar rules to parse arithmetic expressions using +, -, *, and /.
4. Save and close the BISON file.
5. Use the following commands to compile and run:
    o flex art_expr.l
    o bison -d art_expr.y
    o gcc lex.yy.c art_expr.tab.c -o art_expr -lfl
    o ./art_expr
6. Enter expressions as input. If the expression is valid, it displays "valid Expression", otherwise "InvalidExpression".
